# Prompt Library

These prompts correspond to the first CiteTrace architecture and are kept separately for course experiments and reproducibility.

- baseline.txt: deliberately coarse baseline prompt.
- retrieval_planner.txt: cross-retrieval query planning.
- evidence_answer.txt: evidence-constrained answer + atomic claim generation.
- claim_verifier.txt: independent claim-evidence verification.

For prompt ablations, preserve the same paper, question set, model, retrieval store, and generation settings while changing only the prompt condition.
